# Coverage and page planning

Use this checklist to build a brand-specific manual. It is a set of subjects to consider, not a required sequence or a demand for one page per item. Combine related subjects when readable; split dense subjects. Record exclusions and open decisions privately in `coverage`, rather than filling the deck with empty sections.

## Orientation and brand foundation

- Cover: intact left-aligned logo, guide title, version/date from one metadata source.
- Opening: what the guide enables, who uses it, and how to choose the correct asset.
- Navigation: section names and actual final start pages. Add subsection references when helpful. Divider pages introduce what the reader can do next; use them only when they improve navigation and pacing.
- Strategy: audience, purpose, positioning, mission/vision, meaningful differentiator, and relevant context. Do not fabricate market or product claims.
- Values: principle → observable behavior → communication consequence. Personality: define traits through decisions, not adjective lists alone.
- Voice: characteristic, boundary, positive example, correction, and situational variation. Show how a service message, announcement, and promotional line retain a coherent voice.
- Messaging: central promise, supporting messages, descriptor, short and long introductions, and calls to action. Tie claims to actual evidence. Separate approved taglines from proposed options; a standards manual should not leave an unexplained shortlist of competing slogans.

## Logo system

Explain the relationship of symbol, wordmark, and combined lockup using supplied components. Identify the default and appropriate alternatives. Do not reconstruct missing lockups from guessed typography or geometry.

Document actual colorways and background permissions: original, reversed, one-color, image backgrounds, light/dark contexts. A general palette color is not automatically a permitted logo recoloring. Use a variant/background matrix when it clarifies choice.

Clearspace diagrams define the measurement unit from real artwork and show boundaries on all sides. Minimum-size tables identify asset, measurement axis (width or height), digital px, print mm, and known reproduction conditions. Test at actual output size; presentation zoom is not proof of legibility. Proposals remain labeled until validated and approved. Account for small-detail loss in print, embroidery, engraving, or signage only when those media are relevant.

Show placement on a few genuinely used aspect ratios, with safe margins, visual alignment, and explanation of when alternatives apply. Presentation cover alignment remains left at 48 px. Include avatar/app/icon examples only when appropriate; inspect circular crops for containment.

Misuse examples demonstrate real risks: distortion, insufficient clearspace, weak contrast, unauthorized effects/colorways, altered component relationships, or crowded photographic backgrounds. Label each failure and explain the correction. Do not claim a visual technique is universally forbidden when the brand actually uses it.

Construction diagrams are optional in a manual. If useful, derive guides, anchors, and curve handles from source vector paths. Never invent a golden ratio, origin story, or mathematical precision. Use a few informative guides; retain an unobstructed logo nearby.

## Color system

Include every supplied palette entry with unambiguous name, role, HEX, computed RGB, and supplied print specifications. Label generic CMYK conversions approximate. Never guess a spot-color code from a screen swatch. Record output profile/substrate where supplied; print approval depends on production proofing.

Explain functional roles: brand identifier, canvas, text, accent, highlight, UI state where relevant. Show primary/supporting relationships in actual compositions. Distinguish imagery colors from permitted flat fills. If weighting is a rule, show explicit percentages and scope; only use approved ratios or label the proposed ratio. Areas in a palette diagram do not silently define a percentage policy.

Show permitted foreground/background pairs with measured contrast and readable labels. Separate normal text, large text, essential graphics, and decorative use. Passing contrast does not make a pair a brand-approved choice. Include common failures and a better alternative, especially over photographs. Check gradient/transparency endpoints and compositing where relevant. Tints, gradients, opacity, and overprinting require a brand-specific rationale and permission, not a universal ban or default.

## Typography system

Identify primary and secondary families, assigned roles, real available weights/styles, and licensing/access or fallback details where supplied. Use an accurate character specimen including relevant numbers, punctuation, symbols, and supported languages. Wordmark lettering remains distinct from running text.

Define display, heading, subheading, body, caption, quote, attribution, and interface roles as needed. Each specification includes family, weight/style, size with units, line height/leading, tracking with units, case, alignment, and use. Explain conversion if a design-tool tracking value becomes CSS letter-spacing; do not treat numeric tracking units as interchangeable.

Show hierarchy applied to real copy: short message, longer editorial passage with columns/quotes, and a screen with body, labels, and action. Separate print pt/mm from screen px/rem; do not mistake sizes in a scaled slide mockup for production specifications. Show actual intended reading sizes alongside the overview. Include line length, paragraph spacing, wrapping, and mobile adaptations where relevant.

Demonstrate typography failures through relevant corrections: distortion, unauthorized substitution, false bold/italic, cramped leading/tracking, weak hierarchy, poor contrast, rivers or inappropriate justification. These are brand-specific rules, not blanket aesthetic judgments.

## Imagery and visual language

Photo direction should be executable: purpose/subject, environment, lighting, palette/grade, composition, focal point and crop, depth, wardrobe/props where relevant, and relationship to type. Show a small coherent selection with captions explaining decisions. Use separate lifestyle, portrait, product, or studio directions only when these image families exist for the brand.

Demonstrate square, portrait, and landscape crops of the same suitable image, keeping the subject and text-safe space intact. Include concrete unsuitable examples and corrections when available. Distinguish commissioned, supplied, licensed, and generated images. Represent audiences purposefully and respectfully; do not invent restrictive casting demographics or claim usage rights that were not supplied.

Illustration: form language, perspective, dimensionality, palette, detail, texture, and intended contexts. Icons: source family, grid, stroke, corners, fill/outline, optical size, padding, and consistency at actual small sizes. Do not recolor supplied multicolor assets without permission. Patterns: source motif, repeat, density, scale, crop policy, and interaction with text. A logo-derived pattern is an optional proposed extension, not a compulsory identity asset.

Motion/video: lower thirds, caption legibility, title/end frames, logo placement, timing/easing and reduced-motion behavior where relevant. Show a small storyboard with actual specifications; do not invent a universal watermark opacity or mandatory animation.

## Applications as working examples

Choose applications from the brand's real touchpoints. Pair a polished contextual view with a flat, readable, annotated layout. Explain the shared system, not just the object: logo variant, margins, grid, typography, color roles, image crop, information order, and production/export requirements.

- Social: avatar/cover, feed system, individual posts, carousel sequence, stories/reels covers and highlight system when relevant. Show content variety with coherent hierarchy. Treat platform dimensions and UI-safe zones as current production inputs; verify them before claiming platform compliance. Present aspect ratios without pretending a frozen device shell proves compatibility.
- Web/product: responsive content, header/logo, body text, buttons, contrast and imagery. Brand guidance is not automatically a complete product design system.
- Email: newsletter header/body/CTA/footer and signature. Explain fallback fonts, live text, useful alt text, readable image-disabled state, and mobile behavior. A signature is a communication component, not a pasted image of every detail.
- Stationery: business card front/back, letterhead, envelope or note when used. Identify finished size, production margins, bleed/trim, logo dimensions, type sizes, paper/finish only where chosen. Show fold/postal keep-out areas only from actual production requirements. Never import arbitrary stock weights or regional sizes as brand policy.
- Other relevant media: packaging, signage, documents, event materials, merchandise, or advertising. Preserve finished artwork when placing it into mockups. Keep fictional promotional claims out of examples.

## Handoff and maintenance

Close with practical guidance: available files/variants, purpose, format, location, known license or approval limitations, guide version, owner/contact if supplied, and change process. Provide an asset manifest that matches delivered files. Include real links only when verified or supplied. Use one ending; do not append duplicate alternate endings or unused optional chapters.
